# VRChat packages

Unity editor packages for VRChat avatar creators, installable through the VRChat Creator Companion (VCC).

## Install

1. VCC → **Settings** → **Packages** → **Add Repository**
2. Paste `https://shiboneko.github.io/vrc-packages/index.json` and confirm.
3. In your project, add the package.

## Packages

| Package | What it does |
|---|---|
| **Avatar Git Sync** (`onl.shibo.avatar-git-sync`) | Commit & Push your avatar project to any Git host over SSH with one click, restore old versions, work on branches, open merge requests and resolve merge conflicts per file — Git LFS, `.gitignore` and `.meta` files handled for you. Unity 2022.3. |
